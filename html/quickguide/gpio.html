The General Purpose Input Output module consists of five identical register blocks, one for each GPIO port

Base addresses GPIOA: 0x40010800
GPIOB: 0x40010C00
GPIOC: 0x40011000
GPIOD: 0x40011400
GPIOE: 0x40011800

CFGLR Configuration of GPIO port, for lower 8 pins. Configuration of the port is done using the CFGLR and CFGHR for the lower eight and upper eight pins, respectively. For each pin, there are two bits to set the MODE (Input or Output, and speed of output pins), and two bits to set the CoNFiguration (the meaning of these pins depend on whether the pin is an input pin or an output pin):

ODRn (n = 0..15):
If pin is configured as output: Set logic value of GPIO Port pin n
If pin is configured as input: Configures pull-up (1) or pull-down (0), if enabled in CFGLR/CFGHR.
Reading is allowed, but reflects the status of the OUTDR register, not the pin.
