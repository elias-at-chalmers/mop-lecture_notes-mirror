Short descriptions

rd : Destination register
rs, rs1, rs2 : Source registers
imm: Immediate value. Se detailed description for restrictions.
sext: Sign Extend
zext: Zero Extend

Immediate & Address Construction
Instruction Mnemonic Result
lui rd, imm Load upper immediate rd ← imm << 12
auipc rd, imm Add upper immediate to PC rd ← PC + (imm << 12)
li rd, imm Load immediate rd ← imm
la rd, symbol Load address rd ← address
lla rd, symbol Load local address rd ← local address

Control Flow Instructions
Instruction Mnemonic Result
jal rd, offset Jump and link rd ← PC+4; PC ← PC+offset
jalr rd, offset(rs1) Jump and link register rd ← PC+4; PC ← rs1+offset
beq rs1, rs2, offset Branch if equal PC ← PC+offset if rs1 = rs2
bne rs1, rs2, offset Branch if not equal PC ← PC+offset if rs1 ≠ rs2
blt rs1, rs2, offset Branch if less than (signed) PC ← PC+offset if rs1 < rs2
bge rs1, rs2, offset Branch if greater or equal (signed) PC ← PC+offset if rs1 ≥ rs2
bltu rs1, rs2, offset Branch if less than (unsigned) PC ← PC+offset if rs1 < rs2 (u)
bgeu rs1, rs2, offset Branch if greater or equal (unsigned) PC ← PC+offset if rs1 ≥ rs2 (u)
beqz rs, offset Branch if equal to zero PC ← PC+offset if rs = 0
bnez rs, offset Branch if not equal to zero PC ← PC+offset if rs ≠ 0
bgtz rs, offset Branch if greater than zero PC ← PC+offset if rs > 0
bltz rs, offset Branch if less than zero PC ← PC+offset if rs < 0
bgt rs1, rs2, offset Branch if greater than (signed) PC ← PC+offset if rs1 > rs2
ble rs1, rs2, offset Branch if less or equal (signed) PC ← PC+offset if rs1 ≤ rs2
bgtu rs1, rs2, offset Branch if greater than (unsigned) PC ← PC+offset if rs1 > rs2 (u)
bleu rs1, rs2, offset Branch if less or equal (unsigned) PC ← PC+offset if rs1 ≤ rs2 (u)
tail rs Tail call PC ← rs (no return)
j label Unconditional jump PC ← label
jr rs Jump register PC ← rs
ret Return PC ← ra
call symbol Call function ra ← PC+4; PC ← fn
