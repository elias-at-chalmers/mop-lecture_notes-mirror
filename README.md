# Lecture Notes and other text for Machine Oriented Programming

We try to keep the material that eventually ends up on various Canvas pages in this repository. 
To edit/create stuff here: 

0.  You need to install pandoc (https://pandoc.org/installing.html) and you need python installed and on your path
1. To build the html files, you now only run make or press CTRL+SHIFT+B in visual studio code. This will build all modified .md files to html
2. The output goes in a standalone html folder, whose contents you can just copy over to \\sol.ita.chalmers.se\groups\www\www.cse.chalmers.se\resources\mop\lecture_notes
  - To view files when you are editing them, just install "Live Preview" in VSCode, right click one of the html files and choose "Show Preview"
3. All lectures and quickguide and lab1 are already set up to link to these pages is Canvas.
4. There are skeletons in, e.g., labs/lab2.mdwhere you can write your incstructions. Please also put the "solutions" in this folder (see how I did it in Lab1)
5. If you are creating new programming exercises, please put the "solutions" (your working code) in exercises/LectureXX/AssignementXX (see structure of previous exercises).
