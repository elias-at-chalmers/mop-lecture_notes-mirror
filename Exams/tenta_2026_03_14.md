# Uppgift 4 (-1 ... 2p) (C->ASM branches, loops)

You are given this C code

```C
int sum = 0;
int b;
int size;
short a[size];

for (int i = 0; i < size; i++) {
    if (a[i] < b) {
        sum += a[i];
    }
}
```

Which of the assembly implementation is correct? Assume that registers t0-t3 are used like this

```
li t0, 0          # sum = 0
li t1, 0          # i = 0
lw t2, size       
lw t3, b 
la t4, a  
```

Which assembly code below implements it correctly?
